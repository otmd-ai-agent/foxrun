What this demo covers

This small adapter lets Gemma list and create tasks and submit a Markdown deliverable. The visitor accepts the result separately. It does not run Foxrun’s full seven-seat team, autonomous workflows, nightly memory jobs, web capture, or business integrations.

The model is Google’s E4B QAT Q4_0 GGUF, served by Docker Model Runner’s llama.cpp backend. The mobile compressed-tensor checkpoint is a different format. The text-only demo does not load the vision/audio projector.

For the full system, install Foxrun on your machine and connect your preferred supported agent runtime. Keep this forwarded Codespaces port private. To discard the demo, delete the codespace and its storage.
